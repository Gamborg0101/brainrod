## Pipeline
- Write a script JSON to `queue/<key>/<id>.json` (see existing ones for the schema).
- Render: `.venv/bin/python pipeline/render.py queue/<key>/<id>.json`
  → `ready-to-post/<key>/<id>/{video.mp4, thumbnail.jpg, post.md}`. Metadata is stripped.
- Voice: Kokoro (local, Apache-2.0). Fonts: OFL/Apache Google Fonts in `assets/fonts`.
- Check a render by extracting frames with ffmpeg into the scratchpad and viewing them.

## Hard rules
- **Anonymity:** never use the owner's real name, personal email, face or voice anywhere — names, bios, descriptions, file metadata.
- **No reused content:** every script is original. No copied Reddit posts, no ripped footage, music or clips. All visuals are generated by our code.
- **Facts must be true.** Only well-established facts; when unsure, drop it. Kids math must be correct and slow-paced.
- **Variety:** YouTube demonetizes "mass-produced, repetitive" content. Vary hooks, structure, topics and visuals; don't post near-duplicates.
- **Posting is outward-facing:** never upload without the owner approving that batch in the current session.
- Kids channel: always "Made for Kids", no TikTok, no clickbait, nothing scary.
